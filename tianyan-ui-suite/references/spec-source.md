# 天衍量子云平台 UI 生成 Skill · 规范原文

> 本文件为《0818UI skill更新》逐字原文，作为一切视觉争议的仲裁依据。本技能其余文件若与原文冲突，以原文为准。
> （2026-08-18 校订：与仓库根目录《0818UI skill更新.rtf》逐字一致。）

## 功能描述

本 Skill 用于生成符合"天衍量子云平台"设计规范 2.0 的高质量 Vue + Tailwind CSS 页面代码。严格遵守品牌语义、视觉参数、组件白名单和交互反馈规范，输出可直接运行的页面代码。

### 适用场景
- 量子计算云平台功能页面开发
- 数据看板、任务管理、算法展示等企业级应用
- 需要高度规范化、品牌一致性的 UI 场景

---

## 第一部分：顶级强制校验铁则（优先级最高，必须全程遵守）

| 序号 | 规则 |
|------|------|
| 1 | 所有视觉参数 100% 严格匹配下方【结构化 UI 规范】，禁止近似取值、私自微调色号/字号/间距/圆角 |
| 2 | 代码禁止硬编码色值、px 数字；必须先全局抽离主题变量（tailwind.config/scss 变量），所有样式仅调用预设变量名 |
| 3 | 组件必须复用预先封装好的原子基础组件（按钮/输入框/Tab/标签等），禁止手写原生标签自定义样式 |
| 4 | 每一行视觉样式代码后方必须添加注释，标注对应规范条目来源 |
| 5 | 代码输出结束后，强制附带【完整合规自检清单】，逐条核对所有硬约束，标记符合/不符合，不符合则自动修正代码后再输出 |
| 6 | 禁止自行添加规范未提及的渐变、阴影、动效、装饰图形、特殊字体、非标图标 |
| 7 | 输出技术栈固定：Vue + Tailwind CSS |

---

## 第二部分：品牌语义原则

| 原则 | 说明 |
|------|------|
| **确定性反馈** | 每一步操作（提交/计算/任务下发）必须给出明确 loading + 结果轻提示 |
| **低心理负荷** | 信息层级扁平，核心操作路径不超过 3 步 |
| **数据可溯源** | 所有图表/数值区块必须标注数据时间戳或状态标识（等待/运行中/已完成/失败）|
| **静默氛围** | 禁止装饰性动效，仅保留功能指示性动效（hover/focus/加载/状态切换）|

## 第三部分：全局锁定固定参数（不可改动）

### 布局参数
| 属性 | 值 | 说明 |
|------|-----|------|
| 基础画布 | 1920px | 屏幕宽度 |
| **页面版心** | **1640px** | 强制！必须严格遵守 |
| 页面边距 | 左右 140px，顶部 60px，底部 140px | 固定不变 |
| 栅格间距 | 仅 20px、30px | 其余 px 全部禁用 |
| 排版方式 | 上下排列为主 | 版块排列结构多为上下排列 |

### 圆角梯度（唯一标准）
| 元素 | 圆角 |
|------|------|
| 按钮 (btn) | 4px |
| Tag 标签 (tag) | 6px |
| 弹窗/卡片 (modal) | 8px |

### 字体族
- 中文：苹方-简 (PingFang SC)
- 英文/数字：DINPro
- 后备：无衬线字体

## 第六部分：组件白名单 & 固定样式

### 1. 按钮（仅 4 类封装组件）

| 组件 | 用途 |
|------|------|
| `<PrimaryBtn>` | 填充主蓝按钮（主要操作：提交任务/执行） |
| `<LineBtn>` | 线性边框按钮（次要操作：保存草稿/取消） |
| `<TextBtn>` | 文字跳转按钮（导航类：查看详情/返回） |
| `<DisabledBtn>` | 置灰禁用按钮（条件未满足时） |

**约束**：
- 按钮最长不超过 128px，内部文字居中
- 卡片区域底部按钮：只展示文字，禁止边框，颜色 #7A8391，悬停为 #1664FF

### 2. Tab 栏
- 激活态：primary 底色 + 白字
- 未激活：cardBg 底色 + textBody 灰字
- 量子云场景下 Tab 命名示例：概览 | 量子线路 | 任务记录 | 结果分析

### 3. 输入框
- 常态：borderLine 边框
- 聚焦：primary 边框
- 只读：pageBg 浅灰底
- 内边距：12px 16px（仅此一组）

### 4. 图标
- 统一 1.5px 线性轮廓
- 默认 primary 色
- 状态提示红点：danger 色
- 允许图标库：仅限 计算/任务/时钟/图表/设置/导出 6 类线性图标

### 5. Tag 标签
- 圆角：6px (tag)
- 内边距：上下 4px，左右 8px
- 状态映射：

| 状态 | 颜色 |
|------|------|
| 待提交 | primary |
| 运行中 | cyan |
| 已完成 | primaryDeep |
| 失败 | danger |

### 6. 卡片
- 圆角：8px (modal)
- 背景：cardBg
- 内边距：24px（统一）
- 卡片内不出现边框，仅通过阴影或背景色区分层级
- 阴影仅允许 `shadow-sm`

### 7. 状态指示器
- 带圆点状态标识（在线/离线/运行中/错误）
- 圆点直径：8px
- 颜色匹配状态语义

## 第七部分：交互反馈规范（天衍特有）

| 场景 | 反馈方式 |
|------|----------|
| 点击/提交 | loading 态使用按钮内置 spin（尺寸 16px），文字变为"提交中…" |
| 操作成功 | 全局顶部轻提示（toast），持续 3s 自动消失，绿色 #34C759 |
| 操作失败 | 全局顶部错误提示，红色 danger，可手动关闭 |
| 悬浮态 | 所有可点击元素 hover 时透明度变化 0.85 或颜色过渡（仅限 primary 色） |
| 加载骨架屏 | 使用浅灰块 + 流动光效（仅允许 pulse 类，禁止自定义动画） |

---

## 第八部分：禁止黑名单（触碰即违规）

| # | 禁止项 |
|---|--------|
| 1 | 自定义色值、透明度、渐变、阴影、hover 以外动效 |
| 2 | 20/30/140/60/4/6/8 以外任何 px 尺寸数字 |
| 3 | 实心图标、彩色杂图标、粗线条图标 |
| 4 | 自创新组件、异形卡片、不规则圆角 |
| 5 | 加粗规范里标注 Regular 的文字 |
| 6 | Emoji 表情 |
| 7 | 非 DINPro/苹方字体 |
| 8 | 纯装饰性分割线（分割线必须伴随内容分组意义） |
| 9 | 页面内出现超过 3 种交互反馈方式（统一 toast + loading + 状态 tag） |

---

## 第九部分：固定输出格式顺序（不可打乱）

1. **第一步**：输出完整 `tailwind.config.js` 主题配置（注入全部规范变量，包括暗色变量）
2. **第二步**：输出全局原子封装组件代码（Btn/Input/Tab/Tag/Toast/StatusDot 等基础组件）
3. **第三步**：输出当前业务页面/区块 Vue 代码，每行样式带规范注释
4. **第四步**：输出【合规自检清单】逐条核对全部约束，包含"品牌语义符合性"新增检查项

## 第十三部分：快速使用流程

### Step 1: 确认需求
- 页面类型（看板/列表/表单/详情/算法展示）
- 核心功能模块
- 数据展示要求
- 特殊交互需求

### Step 2: 生成配置文件
- 输出 `tailwind.config.js`
- 输出原子组件文件（Button/Tag/Card/StatusDot 等）

### Step 3: 生成业务页面
- 按照规范编写 Vue 组件
- 每行代码添加规范注释
- 确保版心 1640px，所有内容左对齐
- 确保所有数据区域带时间戳

### Step 4: 输出自检清单
- 逐条核对所有约束
- 标记符合/不符合
- 不符合项自动修正
